# KTNH Mon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Pokemon-GO-style creature collecting and dueling game for the 2026 Hack the North Hacker Badge, where NFC stickers are nests and chests, walking spawns encounters, and nearby badges are live opponents.

**Architecture:** Seven Lua modules plus one generated data file, pushed to the badge through the Badge IDE. A creature is a single species id with no per-instance state, so a player's whole collection is a 36-bit bitmap that fits in one radio frame. Duels are one round on a six-type wheel resolved by modular arithmetic, with commit-reveal so neither badge can see the other's pick first. All game logic is pure Lua testable on a host with a mocked `badge` table.

**Tech Stack:** Lua 5.4-compatible (badge runtime), LVGL widget bindings via `badge.ui`, Python 3 + Pillow for the offline art generator, host `lua` 5.5.1 and `luac -p` for tests and syntax checking.

**Spec:** `docs/superpowers/specs/2026-09-19-ktnh-mon-design.md`

## Global Constraints

Copied verbatim from the spec. **Every task's requirements implicitly include this section.**

### Hardware limits

- Screen is 320x240. Widgets capped at **512 live**.
- Lua heap capped at **96 KiB** (`heap_kb=96`). This is an allocation ceiling, NOT reserved RAM. The SoC is an ESP32-C3 with ~400 KB SRAM total and no PSRAM.
- Share bundle: **48 KiB total, 16 files**, paths under 64 bytes and 4 deep.
- `main.lua` at most 64 KiB.
- Filesystem: 64 KiB quota, **16 KiB per read or write**, no seek and no partial read.
- `badge.store`: 32 keys, key names 24 bytes, **string values 128 bytes**, no newlines.
- Radio: **44-byte payload**, broadcast only, 8-slot ring, 4 drained per tick.
- `require`: depth 8, **16 modules** maximum.

### Callback budgets

| Callback | Budget | Old-firmware budget |
|---|---|---|
| main chunk / `on_enter` | 3,000 ms | 250-1,000 ms |
| `on_tick` + queued `on_recv` | 250 ms shared | **6 ms** |
| `on_button` | 1,000 ms | **20 ms** |
| `on_exit` | 1,000 ms | 100 ms |

There is no way to detect which firmware is installed. **Design for the old numbers.** Three consecutive `on_tick` failures suspend tick delivery; one `on_button` failure suspends it immediately.

### Language restrictions

- **No `pcall`.** No `xpcall`, `setmetatable`, `getmetatable`, `load`, `dofile`, `loadfile`.
- No `os`, `io`, `package`, `debug`, `coroutine`. Available: `base`, `table`, `string`, `math`, `utf8`.
- No sleep, no busy waits, no wall clock. `badge.sys.ms()` is monotonic since boot and **resets on reboot**.
- **Use `math.floor` for all rounding**, not `//`. The badge Lua version is unstated; `math.floor` works on every version.
- **Avoid bitwise operators** (`&`, `|`, `~`, `<<`, `>>`) for the same reason. Use arithmetic: `math.floor(x / 2^n) % 2^m`.

### Hard rules

- **Every coordinate, dimension, font size and colour handed to a widget MUST be an integer.**
- **Never bind a control to `badge.input.BUTTON.AUX1`.** It exists in the enum but not on the board. The eight physical buttons are A, B, UP, DOWN, LEFT, RIGHT, START, HOME.
- **Plain ASCII only in on-screen labels.** The bundled fonts have no em dashes, curly quotes or emoji.
- Fonts must be one of `14 16 18 20 22 24`. Colours are `0xRRGGBB` integers.
- Define lifecycle callbacks as **globals**, never `local function on_enter`.
- **Never call `badge.radio` outside `net.lua`.** Never read or write the save outside `own.lua`.
- **Validate every byte arriving from outside the app** - radio payloads, NFC data, save files, sensor returns - before use. Without `pcall` a malformed input is a fatal error, not an exception.
- Widgets are created once in staged construction and **reused**, never recreated. `:delete()` is never called on a game widget.
- `root` is read-only: pass it as a parent, never style, resize, reposition or delete it.

### Game rules

- **36 species**, six of each type. Type ids are wheel positions: **1 Water, 2 Normal, 3 Fire, 4 Ice, 5 Grass, 6 Electric.** This ordering is load-bearing.
- Wheel: `d = (theirs - mine) % 6`; `d` of 1 or 2 wins, 0 or 3 ties, 4 or 5 loses.
- Strength is 1-10, a species property, and the **only** number a creature has. It sets capture difficulty and breaks wheel ties.
- **No XP, no levels, no evolution, no HP, no damage, no moves, no per-instance state.**
- Ownership is a **set**: duplicates bump a Pokedex count, they are not held twice.
- The Pokedex never decreases. The collection does.
- The starter is permanently shielded and can never be a capture target.

## Phase 0: Foundations and hardware truth

Two unknowns cannot be settled on paper: whether `badge.radio` carries binary payloads containing NUL bytes, and what the real heap looks like with `dex.txt` resident. Both change the design if they go the wrong way.

### Task 1: Host mock harness

**Files:**
- Create: `test/mock_badge.lua`
- Create: `test/run.sh`
- Create: `test/test_mock.lua`

**Interfaces:**
- Consumes: nothing
- Produces:
  - `mock.install(opts)` - installs a global `badge` table, returns a control handle `M`
  - `M.reset()` - clears all recorded state
  - `M.ms(v)` / `M.advance(n)` - set or advance the fake clock
  - `M.press(button)` - deliver a PRESSED then RELEASED pair to `on_button`
  - `M.tick(n)` - call `on_tick` n times, advancing 20 ms each
  - `M.leds` - array of 6 `{r,g,b}` tables as of the last `show()`
  - `M.texts` - map of widget handle to its last `set_text` value
  - `M.sent` - array of payloads passed to `badge.radio.send`
  - `M.recv(mac, rssi, payload)` - deliver a frame to the registered handler
  - `M.files` - map of path to file contents
  - `M.widget_count()` - number of live widgets created
  - `opts.accel` - function returning `x,y,z` or nil, defaults to flat gravity
  - `opts.card` - table or nil, returned by `badge.nfc.card()`

```lua
-- pcall. If the harness itself is wrong, every later test lies.
package.path = "test/?.lua;app/?.lua;" .. package.path
local mock = require("mock_badge")
local M = mock.install()

-- Widgets: handles are distinct, text round-trips, counts are tracked.
local root = M.root

M.ms(1000)

M.advance(250)
assert(badge.sys.ms() == 1250)

-- LEDs are staged then shown, exactly like the hardware.
badge.led.clear()
badge.led.set(1, 10, 20, 30)

-- Radio send is recorded; recv is delivered to the registered handler.
badge.radio.enable()
badge.radio.send("PING")
assert(M.sent[1] == "PING")
local got
badge.radio.on_recv(function(mac, rssi, payload) got = payload end)
M.recv("AA:BB", -40, "PONG")
assert(got == "PONG", "recv handler must fire")

-- Files are binary safe, matching badge.fs.
badge.fs.write("appdata/x.dat", "\0\1\255")
assert(badge.fs.read("appdata/x.dat") == "\0\1\255", "fs must be binary safe")
assert(badge.fs.read("appdata/missing.dat") == nil)

-- Store enforces the real 128-byte string cap.
badge.store.set_str("k", "v")
assert(badge.store.get_str("k", "?") == "v")
assert(badge.store.get_str("nope", "dflt") == "dflt")

-- Accelerometer defaults to flat gravity and can be driven.
local x, y, z = badge.sensor.accel()
assert(y == 1000, "default accel must read 1g on y")

-- A harness with no accelerometer must return nil, like real hardware.
local M2 = mock.install({accel = function() return nil, "unavailable" end})
assert(badge.sensor.accel() == nil, "nil accel must pass through")
```

```lua
  function w:set_text(t) M.texts[self] = t end
```

Create `probe/main.lua`:

```lua
-- Throwaway. Answers exactly two questions the design branches on:
-- does badge.radio carry NUL bytes, and what does a 10 KB dex.txt cost
-- on a real ESP32-C3 heap. Delete after phase 0.
local lines = {}
local dex, heap_before, heap_after, peak
local radio_ok, echo_seen, echo_binary = false, false, false
local sent_at = 0

local function say(i, s)
  if lines[i] then lines[i]:set_text(s) end
end

function on_enter(root)
  local bg = badge.ui.box(root, 320, 240)
  bg:set_pos(0, 0)
  bg:style({bg_color = 0x101418})
  for i = 1, 8 do
    lines[i] = badge.ui.label(root, "")
    lines[i]:style({text_font = 14})
    lines[i]:align("top_left", 8, 6 + (i - 1) * 22)
  end

  -- Measure the dex cost with a collection either side, so the number is
  -- the resident string and not accumulated garbage.
  badge.sys.gc_step(); badge.sys.gc_step(); badge.sys.gc_step()
  heap_before = badge.sys.heap()
  dex = badge.fs.read("dex.txt")
  badge.sys.gc_step(); badge.sys.gc_step(); badge.sys.gc_step()
  heap_after = badge.sys.heap()

  say(1, "dex bytes: " .. tostring(dex and #dex or -1))
  say(2, "heap before: " .. heap_before)
  say(3, "heap after:  " .. heap_after)
  say(4, "dex cost:    " .. (heap_after - heap_before))

  local x, y, z = badge.sensor.accel()
  say(5, x and ("accel ok: " .. math.floor(x) .. "," .. math.floor(y) .. "," .. math.floor(z))
        or "ACCEL UNAVAILABLE")

  radio_ok = badge.radio.enable()
  say(6, radio_ok and "radio: on - press A to test binary" or "RADIO FAILED TO ENABLE")
  if radio_ok then
    badge.radio.on_recv(function(mac, rssi, payload)
      if type(payload) ~= "string" then return end
      if #payload < 4 or payload:sub(1, 3) ~= "PRB" then return end
      echo_seen = true
      -- The whole question: did the NUL and the high byte survive the air?
      echo_binary = (#payload == 7)
        and (payload:sub(4, 4) == "\0")
        and (payload:sub(5, 5) == "\255")
        and (payload:sub(6, 6) == "\10")
        and (payload:sub(7, 7) == "\13")
      say(7, "echo len=" .. #payload .. " binary_ok=" .. tostring(echo_binary))
    end)
  end
  say(8, "A send  B stats  HOME exit")
end

function on_tick()
  local st = badge.sys.stats()
  if st and st.lua_peak then peak = st.lua_peak end
end

function on_button(b, kind)
  if kind ~= badge.input.KIND.PRESSED then return end
  if b == badge.input.BUTTON.A and radio_ok then
    -- NUL, 0xFF, LF and CR are the four bytes most likely to be eaten by a
    -- string-oriented transport. If all four return, binary framing is safe.
    badge.radio.send("PRB" .. "\0" .. "\255" .. "\10" .. "\13")
    sent_at = badge.sys.ms()
    say(7, "sent at " .. sent_at .. " - waiting for the other badge")
  elseif b == badge.input.BUTTON.B then
    local st = badge.sys.stats()
    say(2, "used " .. st.lua_used .. " peak " .. st.lua_peak)
    say(3, "limit " .. st.lua_limit .. " free " .. st.free_heap)
    say(4, "widgets " .. st.widgets .. " dropped " .. badge.radio.dropped())
  end
end

function on_exit()
  if radio_ok then
    badge.radio.on_recv(nil)
    badge.radio.disable()
  end
  badge.led.clear()
  badge.led.show()
end
```

- [ ] **Step 1: Write the generator**

Create `tools/gen_dex.py`:

```python
#!/usr/bin/env python3
"""Generates app/dex.txt: 36 creatures, 12 families of 3, 2 families per type.

Art is a 16x16 grid of palette indices, mirrored left-to-right so every
creature reads face-on. Palette: 0 empty, 1 body, 2 shade, 3 accent.

Twelve families must stay distinguishable while sharing only six palettes,
so body plans vary on four INDEPENDENT axes rather than coming from a fixed
list of shapes. Two families share each colour; they must not share a
silhouette.

  python3 tools/gen_dex.py            write app/dex.txt
  python3 tools/gen_dex.py --preview  print all 36 as ASCII
"""
import sys

N = 16                      # grid is N x N
HALF = N // 2               # only the left half is drawn, then mirrored
TYPES = ["WATER", "NORMAL", "FIRE", "ICE", "GRASS", "ELECTRIC"]

# Four independent axes. Twelve families take twelve distinct combinations,
# chosen so that the two families sharing a palette never share an axis value
# in more than one position.
BODY  = ["round", "tall", "squat", "serp"]
HEAD  = ["merged", "distinct", "crested"]
LIMBS = ["none", "two", "four", "fins"]
CROWN = ["none", "horns", "ears", "antennae"]

FAMILY_PLAN = [
    # (body, head, limbs, crown) - index 0..11 is family 1..12
    ("round", "merged",   "two",  "none"),      # 1  Water A
    ("serp",  "distinct", "fins", "antennae"),  # 2  Water B
    ("squat", "distinct", "four", "none"),      # 3  Normal A
    ("tall",  "merged",   "two",  "ears"),      # 4  Normal B
    ("tall",  "crested",  "none", "horns"),     # 5  Fire A
    ("round", "distinct", "four", "antennae"),  # 6  Fire B
    ("squat", "merged",   "fins", "horns"),     # 7  Ice A
    ("tall",  "distinct", "four", "none"),      # 8  Ice B
    ("round", "crested",  "four", "ears"),      # 9  Grass A
    ("serp",  "merged",   "none", "horns"),     # 10 Grass B
    ("squat", "crested",  "two",  "antennae"),  # 11 Electric A
    ("tall",  "distinct", "fins", "ears"),      # 12 Electric B
]

# Six strengths per type: three easy, two middling, one trophy. The trophy
# rotates 8/9/10 across types so no single type owns the hardest catch.
STRENGTH_BASE = [1, 2, 3, 4, 6]
TROPHY = [9, 8, 10, 9, 10, 8]

SYL_A = ["AQUA", "TIDE", "MARI", "DRIP", "FLOW", "WAVE",
         "PLAIN", "DUSTY", "MUND", "TUFT", "PEBB", "FLUFF",
         "EMBER", "CIND", "BLAZE", "SCORCH", "MAGMA", "SOOT",
         "FROST", "GLACI", "RIME", "SLEET", "CHILL", "SHIVER",
         "LEAF", "VINE", "BLOOM", "THORN", "MOSS", "SPROUT",
         "VOLT", "SPARK", "ARC", "JOLT", "OHM", "STATIC"]
SYL_B = ["KIT", "LING", "MAW", "PAW", "WING", "TAIL",
         "FANG", "HORN", "CLAW", "PUP", "MANE", "SCALE"]


def blank():
    return [[0] * N for _ in range(N)]


def ell(g, cx, cy, rx, ry, val):
    """Filled ellipse in grid coordinates. Only the left half is written;
    mirroring happens once at the end."""
    for y in range(N):
        for x in range(HALF):
            dx, dy = (x - cx) / max(rx, 0.01), (y - cy) / max(ry, 0.01)
            if dx * dx + dy * dy <= 1.0:
                g[y][x] = val


def mirror(g):
    for y in range(N):
        for x in range(HALF):
            g[y][N - 1 - x] = g[y][x]


def build(family, stage):
    """stage 0,1,2 - same plan, growing size and gaining markings."""
    body, head, limbs, crown = FAMILY_PLAN[family]
    g = blank()
    grow = stage * 0.6                       # later stages are chunkier

    # --- torso -------------------------------------------------------------
    if body == "round":
        ell(g, 7.5, 10.0, 5.0 + grow, 4.2 + grow, 1)
    elif body == "tall":
        ell(g, 7.5, 10.0, 3.6 + grow * 0.5, 5.6 + grow, 1)
    elif body == "squat":
        ell(g, 7.5, 11.5, 6.0 + grow, 3.2 + grow * 0.5, 1)
    else:  # serpentine - a stacked column with a narrow waist
        ell(g, 7.5, 12.5, 4.4 + grow, 2.8, 1)
        ell(g, 7.5, 8.5, 2.6, 2.6 + grow * 0.5, 1)

    # --- head --------------------------------------------------------------
    if head == "merged":
        hy, hr = 6.5, 3.4 + grow * 0.4
        ell(g, 7.5, hy, hr, hr * 0.85, 1)
    elif head == "distinct":
        hy, hr = 4.6, 3.0 + grow * 0.4
        ell(g, 7.5, hy, hr, hr * 0.9, 1)
    else:  # crested - a head with a swept ridge on top
        hy, hr = 4.8, 3.0 + grow * 0.4
        ell(g, 7.5, hy, hr, hr * 0.9, 1)
        for x in range(2, 7):
            yy = 2 - (x - 2) // 2
            if 0 <= yy < N:
                g[yy][x] = 1

    # --- crown -------------------------------------------------------------
    top = int(hy - hr)
    if crown == "horns":
        for k in range(2 + stage):
            yy, xx = top - 1 - k, 4 - (k // 2)
            if 0 <= yy < N and 0 <= xx < HALF:
                g[yy][xx] = 1
    elif crown == "ears":
        for k in range(3 + stage):
            yy, xx = top - k, 4
            if 0 <= yy < N:
                g[yy][xx] = 1
    elif crown == "antennae":
        for k in range(2 + stage):
            yy, xx = top - 1 - k, 5 - k
            if 0 <= yy < N and 0 <= xx < HALF:
                g[yy][xx] = 1
        yy = top - 2 - stage
        if 0 <= yy < N:
            g[yy][max(0, 5 - (1 + stage))] = 3   # glowing tip

    # --- limbs -------------------------------------------------------------
    base = 14 if body == "squat" else 15
    if limbs in ("two", "four"):
        for xx in (4, 6):
            for yy in (base - 1, base):
                if 0 <= yy < N:
                    g[yy][xx] = 1
        if limbs == "four":
            for yy in (10, 11):
                g[yy][1] = 1
    elif limbs == "fins":
        for yy in (9, 10, 11):
            g[yy][0] = 1
            g[yy][1] = 1

    # --- eyes, always last so nothing overwrites them ----------------------
    ey = int(hy)
    if 0 <= ey < N:
        g[ey][5] = 3
        if stage >= 1 and 0 <= ey < N:
            g[ey][4] = 3      # bigger eye on later stages

    # --- belly shading -----------------------------------------------------
    for y in range(N):
        for x in range(HALF):
            if g[y][x] == 1 and y >= 11 and x <= 3:
                g[y][x] = 2
    if stage == 2:
        for x in range(2, 6):
            if g[12][x] == 1:
                g[12][x] = 2

    mirror(g)
    return g


def name_for(idx, family, stage):
    a = SYL_A[(family // 2) * 6 + (family % 2) * 3 + stage]
    b = SYL_B[(family + stage) % len(SYL_B)]
    n = (a + b)[:10]
    return n if len(n) >= 4 else (n + "MON")[:10]


def rows(g):
    return "".join("".join(str(c) for c in row) for row in g)


def generate():
    out = []
    sid = 0
    for t in range(6):                       # type 1..6
        strengths = STRENGTH_BASE + [TROPHY[t]]
        for fslot in range(2):               # two families per type
            family = t * 2 + fslot
            for stage in range(3):
                sid += 1
                s = strengths[fslot * 3 + stage]
                art = rows(build(family, stage))
                assert len(art) == 256, len(art)
                nm = name_for(sid, family, stage)
                out.append(f"{sid:02d} {nm} {t + 1} {s} {family + 1} {art}")
    assert len(out) == 36
    return out


def preview(lines):
    glyph = {"0": " ", "1": "#", "2": "+", "3": "o"}
    for i in range(0, 36, 3):
        trio = lines[i:i + 3]
        heads = []
        grids = []
        for ln in trio:
            p = ln.split(" ")
            heads.append(f"{p[1]} s{p[3]}".ljust(18))
            grids.append([p[5][r * 16:(r + 1) * 16] for r in range(16)])
        print("".join(heads))
        for r in range(16):
            print("".join("".join(glyph[c] for c in gr[r]) + "  " for gr in grids))
        print()


if __name__ == "__main__":
    lines = generate()
    if "--preview" in sys.argv:
        preview(lines)
    else:
        with open("app/dex.txt", "w") as f:
            f.write("\n".join(lines) + "\n")
        total = sum(len(l) + 1 for l in lines)
        print(f"wrote app/dex.txt: 36 species, {total} bytes")
```

```lua
-- Species table. dex.txt is held as ONE string with an offset index; the
-- alternative, 36 separate line strings, roughly doubles the heap cost of
-- the largest single allocation in the app.
local M = {}

M.COUNT = 36

-- Type ids ARE positions on the duel wheel. Reordering this table silently
-- changes every matchup in the game - see duel.lua's compare().
M.TYPE = {WATER = 1, NORMAL = 2, FIRE = 3, ICE = 4, GRASS = 5, ELECTRIC = 6}
M.TYPE_NAME = {"WATER", "NORMAL", "FIRE", "ICE", "GRASS", "ELECTRIC"}

-- {body, shade, accent} per type. Accent is always bright enough to read as
-- an eye against its own body colour on the badge's dark theme.
M.TYPE_COLOR = {
  {0x2F6FE0, 0x1B4794, 0xBFE0FF},  -- Water
  {0x9A9488, 0x6B665C, 0xF0EBE0},  -- Normal
  {0xE0452F, 0x94291B, 0xFFD9A8},  -- Fire
  {0x6FC8E0, 0x3E8AA0, 0xEAFBFF},  -- Ice
  {0x46B355, 0x2A7034, 0xE2FFD1},  -- Grass
  {0xE0C02F, 0x9A821B, 0xFFF8C2},  -- Electric
}

local raw = nil          -- the whole file, one string
local starts = {}        -- starts[id] = byte offset of that line
local stops = {}         -- stops[id]  = byte offset of its last character

local function valid(id)
  return type(id) == "number" and id == math.floor(id) and id >= 1 and id <= M.COUNT
end

-- One shared parse. Called per accessor rather than cached, because caching
-- 36 parsed rows costs more heap than re-matching the handful of lines a
-- screen actually touches.
local function fields(id)
  if not valid(id) or not raw then return nil end
  local line = string.sub(raw, starts[id], stops[id])
  return string.match(line, "^(%d+) (%u+) (%d) (%d+) (%d+) ([0-3]+)$")
end

function M.load()
  local data, err = badge.fs.read("dex.txt")
  if not data then return false, err or "dex.txt missing" end
  raw = data
  starts, stops = {}, {}
  local i, n = 1, 0
  while i <= #raw do
    local nl = string.find(raw, "\n", i, true)
    local last = (nl and nl - 1) or #raw
    if last >= i then
      n = n + 1
      starts[n] = i
      stops[n] = last
    end
    if not nl then break end
    i = nl + 1
  end
  if n ~= M.COUNT then
    raw = nil
    return false, "expected " .. M.COUNT .. " species, found " .. n
  end
  return true
end

function M.name(id)
  local _, nm = fields(id)
  return nm
end

function M.type(id)
  local _, _, t = fields(id)
  return t and tonumber(t) or nil
end

function M.strength(id)
  local _, _, _, s = fields(id)
  return s and tonumber(s) or nil
end

function M.family(id)
  local _, _, _, _, f = fields(id)
  return f and tonumber(f) or nil
end

function M.art(id)
  local _, _, _, _, _, a = fields(id)
  return a
end

function M.first_of_type(t)
  for id = 1, M.COUNT do
    if M.type(id) == t then return id end
  end
  return nil
end

return M
```

```lua
-- Row-run decoding. A 16x16 creature averages about 33 runs and peaks near
-- 40, against 256 cells - which is why one 48-box pool can serve every
-- screen instead of the renderer eating half the widget cap.
function M.runs(id)
  local art = M.art(id)
  local out = {}
  if not art then return out end
  for row = 0, 15 do
    local base = row * 16
    local col = 0
    while col < 16 do
      local c = string.byte(art, base + col + 1) - 48
      if c == 0 then
        col = col + 1
      else
        local len = 1
        while col + len < 16
          and (string.byte(art, base + col + len + 1) - 48) == c do
          len = len + 1
        end
        out[#out + 1] = {row = row, col = col, len = len, palette = c}
        col = col + len
      end
    end
  end
  return out
end

function M.new_pool(parent, size)
  local pool = {}
  for i = 1, size do
    local b = badge.ui.box(parent, 1, 1)
    b:hidden(true)
    pool[i] = b
  end
  return pool
end

function M.hide_pool(pool)
  for i = 1, #pool do pool[i]:hidden(true) end
end

-- Paints species `id` into `pool`. Colours come from the type palette, not
-- from the art, so one grid renders in all six type colours.
function M.paint(pool, id, x, y, cell)
  local runs = M.runs(id)
  local pal = M.TYPE_COLOR[M.type(id) or 0]
  if not pal or #runs == 0 then
    M.hide_pool(pool)
    return 0
  end
  local n = #runs
  if n > #pool then n = #pool end
  for i = 1, n do
    local r = runs[i]
    local b = pool[i]
    b:set_pos(x + r.col * cell, y + r.row * cell)
    b:set_size(r.len * cell, cell)
    b:set_color(pal[r.palette])
    b:hidden(false)
  end
  for i = n + 1, #pool do pool[i]:hidden(true) end
  return n
end
```

```lua
-- All player state. NOTHING else in the app reads or writes the save.
--
-- A creature has no per-instance state, so "owning a species" is one bit and
-- the whole collection is 36 bits. That is what lets a duel frame carry an
-- entire collection in 5 bytes.
local dex = require("dex")

local M = {}

local PATH = "appdata/save.dat"
local VERSION = 1
local BM_BYTES = 5          -- ceil(36 / 8)
local TAG_ENTRIES = 24
local TAG_SIZE = 14         -- 8 hex chars of UID + 6 digits of step count

local st

local function fresh()
  local s = {ver = VERSION, starter = 0, bm = {}, dexc = {},
             steps = 0, balls = 0, eggs = 0, tags = {}}
  for i = 1, BM_BYTES do s.bm[i] = 0 end
  for i = 1, dex.COUNT do s.dexc[i] = 0 end
  return s
end

local function valid(id)
  return type(id) == "number" and id == math.floor(id)
     and id >= 1 and id <= dex.COUNT
end

local function clamp(v, lo, hi)
  if v < lo then return lo end
  if v > hi then return hi end
  return v
end

local function byte_at(s, i)
  return string.byte(s, i) or 0
end

-- Bit i of the 36-bit collection lives in byte floor((i-1)/8)+1 at position
-- (i-1)%8. Arithmetic rather than bitwise, because the badge Lua version is
-- unstated and math.floor works on all of them.
local function bit_parts(id)
  local z = id - 1
  return math.floor(z / 8) + 1, 2 ^ (z % 8)
end

function M.has(id)
  if not valid(id) then return false end
  local byte, mask = bit_parts(id)
  return math.floor(st.bm[byte] / mask) % 2 == 1
end

function M.add(id)
  if not valid(id) or M.has(id) then return end
  local byte, mask = bit_parts(id)
  st.bm[byte] = st.bm[byte] + mask
end

function M.remove(id)
  if not valid(id) or not M.has(id) then return end
  local byte, mask = bit_parts(id)
  st.bm[byte] = st.bm[byte] - mask
end

function M.caught(id)
  if not valid(id) then return 0 end
  return st.dexc[id]
end

-- The one asymmetry that matters: add() can be undone by remove(), the
-- Pokedex count cannot. Losing a duel must never erase a record.
function M.record_catch(id)
  if not valid(id) then return end
  M.add(id)
  st.dexc[id] = clamp(st.dexc[id] + 1, 0, 255)
end

function M.starter() return st.starter end

function M.set_starter(id)
  if not valid(id) then return end
  st.starter = id
  M.record_catch(id)
end

function M.is_shielded(id) return valid(id) and st.starter == id end

function M.bitmap()
  local out = {}
  for i = 1, BM_BYTES do out[i] = string.char(st.bm[i] % 256) end
  return table.concat(out)
end

-- Decodes a PEER's bitmap. Never trusts length or the spare high bits:
-- species 37-40 exist in byte 5 and must never escape into a species id.
function M.from_bitmap(s)
  local out = {}
  if type(s) ~= "string" then return out end
  for id = 1, dex.COUNT do
    local z = id - 1
    local b = byte_at(s, math.floor(z / 8) + 1)
    if math.floor(b / 2 ^ (z % 8)) % 2 == 1 then out[#out + 1] = id end
  end
  return out
end

function M.types_held()
  local seen, out = {}, {}
  for id = 1, dex.COUNT do
    if M.has(id) then
      local t = dex.type(id)
      if t and not seen[t] then seen[t] = true; out[#out + 1] = t end
    end
  end
  table.sort(out)
  return out
end

function M.balls() return st.balls end
function M.add_balls(n) st.balls = clamp(st.balls + n, 0, 255) end
function M.spend_ball()
  if st.balls <= 0 then return false end
  st.balls = st.balls - 1
  return true
end

function M.eggs() return st.eggs end
function M.add_egg() st.eggs = clamp(st.eggs + 1, 0, 255) end
function M.take_egg()
  if st.eggs <= 0 then return false end
  st.eggs = st.eggs - 1
  return true
end

function M.steps() return st.steps end
function M.add_step() st.steps = clamp(st.steps + 1, 0, 4294967295) end

-- Cooldowns are counted in STEPS, not milliseconds: badge.sys.ms() resets on
-- reboot, so a time-based cooldown would be refreshed by a power cycle.
function M.tag_seen(uid)
  for i = 1, #st.tags do
    if st.tags[i].uid == uid then return st.tags[i].step end
  end
  return nil
end

function M.tag_visit(uid)
  for i = 1, #st.tags do
    if st.tags[i].uid == uid then st.tags[i].step = st.steps; return end
  end
  if #st.tags >= TAG_ENTRIES then table.remove(st.tags, 1) end
  st.tags[#st.tags + 1] = {uid = uid, step = st.steps}
end

local function u32(v)
  v = math.floor(v) % 4294967296
  return string.char(v % 256, math.floor(v / 256) % 256,
                     math.floor(v / 65536) % 256, math.floor(v / 16777216) % 256)
end

function M.save()
  local p = {string.char(VERSION), string.char(st.starter % 256)}
  for i = 1, BM_BYTES do p[#p + 1] = string.char(st.bm[i] % 256) end
  for i = 1, dex.COUNT do p[#p + 1] = string.char(st.dexc[i] % 256) end
  p[#p + 1] = u32(st.steps)
  p[#p + 1] = string.char(st.balls % 256)
  p[#p + 1] = string.char(st.eggs % 256)
  for i = 1, #st.tags do
    local uid = string.sub(st.tags[i].uid, 1, 8)
    while #uid < 8 do uid = uid .. " " end
    p[#p + 1] = uid .. string.format("%06d", st.tags[i].step % 1000000)
  end
  badge.fs.write(PATH, table.concat(p))
  badge.store.set_int("sv", VERSION)
  return true
end

-- Never errors. A truncated, empty, absent or garbage file all load as a
-- fresh save, because there is no pcall and a save-format bug would
-- otherwise brick the app on launch with no way back.
function M.load()
  st = fresh()
  local data = badge.fs.read(PATH)
  -- 43 is the end of the Pokedex block: everything before it is essential
  -- state, everything after it is recoverable defaults.
  if type(data) ~= "string" or #data < 43 then return end
  if byte_at(data, 1) ~= VERSION then return end

  local starter = byte_at(data, 2)
  st.starter = (starter >= 1 and starter <= dex.COUNT) and starter or 0
  for i = 1, BM_BYTES do st.bm[i] = byte_at(data, 2 + i) end
  -- Species 37-40 do not exist; clear the spare high bits of the last byte
  -- so a corrupt file cannot make from_bitmap or the UI see a phantom id.
  st.bm[BM_BYTES] = st.bm[BM_BYTES] % 16
  for i = 1, dex.COUNT do st.dexc[i] = byte_at(data, 7 + i) end

  if #data >= 47 then
    st.steps = byte_at(data, 44) + byte_at(data, 45) * 256
             + byte_at(data, 46) * 65536 + byte_at(data, 47) * 16777216
  end
  if #data >= 48 then st.balls = byte_at(data, 48) end
  if #data >= 49 then st.eggs = byte_at(data, 49) end

  local off = 50
  while off + TAG_SIZE - 1 <= #data and #st.tags < TAG_ENTRIES do
    local uid = string.sub(data, off, off + 7)
    local n = tonumber(string.sub(data, off + 8, off + 13))
    if n then st.tags[#st.tags + 1] = {uid = uid, step = n} end
    off = off + TAG_SIZE
  end
end

return M
```

```lua
  -- else. This is the pattern the guide prescribes for large boards, and it

function on_tick()
  local now = badge.sys.ms()

  -- A gap this large means ticks were paused - almost always the HOME
  -- confirmation dialog, which does not notify Lua when it closes. Anything
  -- timing-sensitive must restart rather than fast-forward.
  did_resume = (now - last_tick_ms) > 300
  last_tick_ms = now

  if not is_ready then
    local built = 0
    while qhead <= #queue and built < BUILD_BATCH do
      queue[qhead]()
      qhead = qhead + 1
      built = built + 1
    end
  end

  local s = screens[cur]
  if s and s.tick then s.tick(now) end

  if now - last_led >= LED_MS then
    last_led = now
    draw_leds(now)
  end
end

function on_button(b, kind)
  if kind ~= badge.input.KIND.PRESSED then return end
  if not is_ready then return end
  local s = screens[cur]
  if s and s.button then s.button(b) end
end

function on_exit()
  own.save()
  badge.led.clear()
  badge.led.show()
```

```lua
-- Throw detection, the shake window, catch probability and step counting.
-- All four read the same accelerometer stream, so they live together.
local M = {}

M.NONE, M.NICE, M.GREAT, M.EXCELLENT = 0, 1, 2, 3
M.GRADE_NAME = {[0] = "miss", "nice", "great", "excellent"}
M.THROW_MULT = {[0] = 0, 10, 15, 20}

-- CALIBRATION KNOBS. A real accelerometer reads off and every badge differs;
-- these are starting points measured against a deliberate hard throw, not
-- constants. Tune them on hardware before judging the catch rates.
M.THRESH = {
  start = 1800,               -- mg above gravity that begins a throw
  finish = 600,               -- mg below which the throw is over
  great = 2500,
  excellent = 3500,
  straight_great = 140,       -- 0-255, forward energy share
  straight_excellent = 200,
}

local CALIB_SAMPLES = 25
local END_HOLD = 4            -- consecutive quiet samples that end a throw
local MAX_SAMPLES = 60        -- a "throw" longer than this is the player waving

local function abs(v) if v < 0 then return -v end return v end

function M.new_thrower()
  return {
    phase = "calibrating", calib = 0,
    gx = 0, gy = 1000, gz = 0,
    peak = 0, lateral = 0, n = 0, quiet = 0,
    grade = M.NONE,
  }
end

function M.reset(th)
  th.phase = "calibrating"
  th.calib = 0
  th.peak, th.lateral, th.n, th.quiet = 0, 0, 0, 0
  th.grade = M.NONE
end

-- Forward energy against total energy, 0-255. A throw straight out from the
-- chest scores high; a wild sideways swing scores low even if it is violent.
local function straightness(peak, lateral, n)
  if n == 0 or peak <= 0 then return 0 end
  local fwd = peak * peak * n
  local denom = fwd + lateral
  if denom <= 0 then return 0 end
  return math.floor(fwd * 255 / denom)
end

local function grade_of(peak, straight)
  if peak >= M.THRESH.excellent and straight >= M.THRESH.straight_excellent then
    return M.EXCELLENT
  end
  if peak >= M.THRESH.great and straight >= M.THRESH.straight_great then
    return M.GREAT
  end
  if peak >= M.THRESH.start then return M.NICE end
  return M.NONE
end

-- Returns true on the tick a throw COMPLETES. th.grade holds the result.
function M.feed(th, x, y, z)
  if x == nil then return false end
  x, y, z = math.floor(x), math.floor(y), math.floor(z)

  if th.phase == "calibrating" then
    th.calib = th.calib + 1
    -- A slow exponential settle, so the resting orientation is learned
    -- without needing the player to hold perfectly still.
    th.gx = th.gx + math.floor((x - th.gx) / 4)
    th.gy = th.gy + math.floor((y - th.gy) / 4)
    th.gz = th.gz + math.floor((z - th.gz) / 4)
    if th.calib >= CALIB_SAMPLES then th.phase = "idle" end
    return false
  end

  local dy = y - th.gy
  local lat = abs(x - th.gx) + abs(z - th.gz)

  if th.phase == "idle" then
    if dy >= M.THRESH.start then
      th.phase = "throwing"
      th.peak, th.lateral, th.n, th.quiet = dy, lat * lat, 1, 0
    end
    return false
  end

  -- phase == "throwing"
  th.n = th.n + 1
  if dy > th.peak then th.peak = dy end
  th.lateral = th.lateral + lat * lat

  if abs(dy) <= M.THRESH.finish then
    th.quiet = th.quiet + 1
  else
    th.quiet = 0
  end

  if th.quiet >= END_HOLD or th.n >= MAX_SAMPLES then
    th.grade = grade_of(th.peak, straightness(th.peak, th.lateral, th.n))
    th.phase = "idle"
    th.peak, th.lateral, th.n, th.quiet = 0, 0, 0, 0
    return true
  end
  return false
end

return M
```

```lua
M.COUNT_MS = 3000            -- countdown before the window opens
M.SHAKE_MS = 5000            -- the window itself
M.SHAKE_TARGET = 12          -- shakes for a full 1.0x, a tuning knob

function M.new_window()
  return {started = nil, shakes = 0, phase = "countdown"}
end

-- Driven by absolute milliseconds, never by a tick count. Ticks stop
-- entirely while the HOME confirmation is open and badge.sys.ms() does not,
-- so a tick-counted window would silently drain behind the dialog.
function M.window_step(w, now, shook)
  if w.started == nil then w.started = now end
  local dt = now - w.started
  if dt < M.COUNT_MS then
    w.phase = "countdown"
  elseif dt < M.COUNT_MS + M.SHAKE_MS then
    w.phase = "shaking"
    -- Shakes only count once the window is actually open.
    if shook then w.shakes = w.shakes + 1 end
  else
    w.phase = "done"
  end
  return w.phase
end

function M.shake_mult(w)
  local ratio = w.shakes / M.SHAKE_TARGET
  if ratio > 1 then ratio = 1 end
  return 5 + math.floor(5 * ratio)
end

-- Linear from 70 percent at strength 1 to 8 percent at strength 10. This is
-- the entire "stronger pokemon are harder to catch" rule.
function M.base_percent(strength)
  if type(strength) ~= "number" then return 5 end
  if strength < 1 then strength = 1 end
  if strength > 10 then strength = 10 end
  return 70 - math.floor((strength - 1) * 62 / 9)
end

-- Integer arithmetic throughout, clamped to 5-95. Shared by wild encounters
-- and duel captures so there is exactly one thing to balance.
function M.chance(strength, shake_mult, throw_mult, times_caught)
  if throw_mult == nil or throw_mult <= 0 then return 5 end
  local copies = times_caught or 0
  if copies > 5 then copies = 5 end
  local dex_bonus = 100 + 10 * copies
  local c = math.floor(M.base_percent(strength) * shake_mult * throw_mult
                       * dex_bonus / 1000)
  if c < 5 then return 5 end
  if c > 95 then return 95 end
  return c
end
```

```lua
M.STEP_THRESH = 260           -- mg above resting magnitude that opens a step
M.STEP_CLEAR = 120            -- mg it must fall back under to re-arm
M.STEP_REFRACTORY_MS = 250    -- fastest credible stride

function M.new_stepper()
  return {calib = 0, rest = 1000, armed = true, last = -100000}
end

-- Hysteresis plus a refractory period. Without the hysteresis a single
-- bounce oscillating across the threshold counts several times; without the
-- refractory period shaking the badge reads as sprinting.
function M.step_feed(sp, x, y, z, now)
  if x == nil then return false end
  local mag = math.floor(math.sqrt(x * x + y * y + z * z))

  if sp.calib < 25 then
    sp.calib = sp.calib + 1
    sp.rest = sp.rest + math.floor((mag - sp.rest) / 4)
    return false
  end

  local dev = mag - sp.rest
  if dev < 0 then dev = -dev end

  if sp.armed and dev >= M.STEP_THRESH then
    sp.armed = false
    if now - sp.last >= M.STEP_REFRACTORY_MS then
      sp.last = now
      return true
    end
  elseif not sp.armed and dev <= M.STEP_CLEAR then
    sp.armed = true
  end
  return false
end
```

```lua
function encounter_tick(now)
  if wild.phase == "over" then
    if now % 4000 < 30 then show("MAP") end
    return
  end

  local x, y, z = badge.sensor.accel()
  if x == nil then
    wild.nil_reads = wild.nil_reads + 1
    -- Three consecutive nil reads is a dead accelerometer, not a blip. The
    -- bar is the only remaining way to play, so switch permanently.
    if wild.nil_reads >= 3 and not accel_gone then
      accel_gone = true
      wild.phase = "bar"
    end
  else
    wild.nil_reads = 0
  end

  if wild.phase == "bar" then
    wild.bar = wild.bar + wild.dir * 4
    if wild.bar >= 100 then wild.bar, wild.dir = 100, -1 end
    if wild.bar <= 0 then wild.bar, wild.dir = 0, 1 end
    screens.ENCOUNTER.meter:set_value(math.floor(wild.bar))
    screens.ENCOUNTER.hint:set_text("A to stop   B flee   balls " .. wild.balls)
    return
  end

  -- A resume gap means the HOME dialog ate the window. Restart rather than
  -- let five seconds drain where the player could not see or act on it.
  if resumed() then
    start_attempt()
    return
  end

  local phase = catch.window_step(wild.win, now, badge.sensor.shake())
  if phase == "countdown" then
    wild.phase = "countdown"
    local left = math.ceil((catch.COUNT_MS - (now - wild.win.started)) / 1000)
    screens.ENCOUNTER.hint:set_text("get ready " .. left)
    led_scene("countdown")
  elseif phase == "shaking" then
    wild.phase = "shaking"
    screens.ENCOUNTER.meter:set_value(
      math.floor(math.min(wild.win.shakes, catch.SHAKE_TARGET)
                 * 100 / catch.SHAKE_TARGET))
    screens.ENCOUNTER.hint:set_text("SHAKE!   balls " .. wild.balls)
    led_scene("shaking")
  else
    wild.phase = "throw"
    screens.ENCOUNTER.hint:set_text("THROW IT   balls " .. wild.balls)
    if x and catch.feed(wild.th, x, y, z) then
      finish_attempt(catch.THROW_MULT[wild.th.grade])
    end
  end
end
```

```lua
-- Accepts ONLY fixed-uid NTAG and Ultralight stickers.
--
-- Without this, the game has an unbounded economy: most payment cards and
-- every phone doing HCE present a randomized uid on each tap, so waving one
-- card repeatedly mints a fresh chest every time. Calibrate against a real
-- venue sticker before trusting the constants - read one with the guide's
-- NFC Card Viewer example and widen the filter if it is not NTAG.
function nfc_usable(card)
  if type(card) ~= "table" then return false end
  local uid = card.uid
  if type(uid) ~= "string" then return false end
  if #uid ~= 14 then return false end              -- 7 bytes as hex
  if card.sak ~= 0 then return false end           -- 0x20 is a phone or EMV
  if string.sub(uid, 1, 2) == "08" then return false end  -- ISO random-id marker
  return true
end

-- A cheap deterministic mix. Two tags whose uids differ in one nibble must
-- land in different roles, so the hash folds every character.
function uid_hash(uid)
  local h = 2166
  for i = 1, #uid do
    h = (h * 31 + string.byte(uid, i)) % 65521
  end
  return h
end

function tag_role(uid)
  if uid_hash(uid) % 8 == 0 then return "chest" end
  return "nest"
end

function tag_type(uid)
  return math.floor(uid_hash(uid) / 8) % 6 + 1
end

function nfc_poll()
  if not nfc_ok then return end
  local card = badge.nfc.card()
  if card == nil then last_uid = nil; return end
  if card.uid == last_uid then return end
  last_uid = card.uid

  if not nfc_usable(card) then
    screens.MAP.radio:set_text("not a sticker")
    return
  end

  local seen = own.tag_seen(card.uid)
  if seen and (own.steps() - seen) < TAG_COOLDOWN_STEPS then
    screens.MAP.radio:set_text("spent - walk "
      .. (TAG_COOLDOWN_STEPS - (own.steps() - seen)) .. " steps")
    return
  end
  own.tag_visit(card.uid)

  if tag_role(card.uid) == "chest" then
    open_chest()
  else
    spawn_wild(nil, tag_type(card.uid))
  end
end
```

```lua
-- Duel rules. Pure: no rendering, no radio, no save. That is what lets
-- test_duel.lua run two complete players inside one Lua process.
local dex = require("dex")

local M = {}

M.WIN, M.TIE, M.LOSS = 1, 0, -1

-- THE WHEEL. Type ids ARE positions on a circle - Water 1 through Electric 6
-- - so the entire 36-entry chart is one modular subtraction. A lookup table
-- would be dead weight and could drift out of sync with itself; this cannot.
--
-- Each type beats the next TWO, ties the one OPPOSITE, loses to the previous
-- two. Reordering dex.TYPE silently rewrites every matchup in the game.
function M.compare(mine, theirs)
  if type(mine) ~= "number" or type(theirs) ~= "number" then return M.TIE end
  if mine < 1 or mine > 6 or theirs < 1 or theirs > 6 then return M.TIE end
  local d = (theirs - mine) % 6
  if d == 1 or d == 2 then return M.WIN end
  if d == 4 or d == 5 then return M.LOSS end
  return M.TIE
end

-- Full resolution from my perspective. `coin` is 0 or 1 and comes from the
-- HOST's RNG, so both badges agree without needing a shared seed.
function M.resolve(mine, theirs, coin)
  local mt, tt = dex.type(mine), dex.type(theirs)
  local r = M.compare(mt, tt)
  if r ~= M.TIE then return r end

  -- Strength decides only when the wheel does not. A weak Water still beats
  -- a strong Fire: type outranks strength, always.
  local ms, ts = dex.strength(mine) or 0, dex.strength(theirs) or 0
  if ms > ts then return M.WIN end
  if ms < ts then return M.LOSS end
  return (coin == 1) and M.WIN or M.LOSS
end

function M.legal(ids)
  if type(ids) ~= "table" or #ids ~= 3 then return false end
  local seen = {}
  for i = 1, 3 do
    local t = dex.type(ids[i])
    if t == nil or seen[t] then return false end
    seen[t] = true
  end
  return true
end

return M
```

```lua
-- FNV-1 at 16 bits, using multiply-then-add rather than the FNV-1a xor
-- variant, because bitwise operators are avoided throughout this app: the
-- badge's Lua version is unstated and arithmetic works on all of them.
-- h * 257 peaks at about 16.8 million, exact in any Lua number type.
local FNV_OFFSET, FNV_PRIME = 33052, 257

function M.fnv16(s)
  if type(s) ~= "string" then return 0 end
  local h = FNV_OFFSET
  for i = 1, #s do
    h = (h * FNV_PRIME) % 65536
    h = (h + string.byte(s, i)) % 65536
  end
  return h
end

function M.commit(pick, nonce)
  return M.fnv16(string.char(pick % 256, nonce % 256, math.floor(nonce / 256) % 256))
end

-- NOT cryptography. A purpose-built cheating app could brute-force three
-- picks across 65,536 nonces. That is the accepted ceiling: a dozen lines
-- that defeat every accidental and casual case. The upgrade path is a wider
-- hash, not a different protocol.
function M.verify(commitment, pick, nonce)
  if type(commitment) ~= "number" then return false end
  if type(pick) ~= "number" or pick < 1 or pick > 3 then return false end
  if type(nonce) ~= "number" or nonce < 0 or nonce > 65535 then return false end
  return M.commit(pick, nonce) == commitment
end

function M.new_nonce()
  return badge.sys.random(65536)
end
```

```lua
-- The ONLY module that touches badge.radio, and the only one that ever sees
-- a raw payload.
--
-- The Lua channel is shared with every other app on every other badge in the
-- room, and there is no pcall. A single malformed frame that reaches the
-- game logic is a fatal error that suspends tick delivery. So: validate
-- first, clamp everything, and return nil for anything that is not exactly
-- right. Never "best effort".
local dex = require("dex")

local M = {}

M.PREFIX = "KM1"
M.KIND = {
  BEACON = "B", CHALLENGE = "C", ACCEPT = "A", COMMIT = "H",
  REVEAL = "R", RESULT = "S", TARGET = "T", OUTCOME = "E",
}

-- Exact payload length per kind, EXCLUDING the 4-byte prefix and kind.
-- BEACON is variable because it carries a name; everything else is fixed,
-- and a length mismatch is an instant reject.
-- Kind whitelist only. The authoritative length check lives in
-- unpack_body(), next to the fields it guards, so the two can never drift.
local KNOWN = {B = true, C = true, A = true, H = true,
               R = true, S = true, T = true, E = true}

local hex_mode = false
local enabled = false
local handler = nil

function M.set_hex(on) hex_mode = on and true or false end

local HEXD = "0123456789ABCDEF"

local function to_hex(s)
  local o = {}
  for i = 1, #s do
    local b = string.byte(s, i)
    o[#o + 1] = string.sub(HEXD, math.floor(b / 16) + 1, math.floor(b / 16) + 1)
    o[#o + 1] = string.sub(HEXD, b % 16 + 1, b % 16 + 1)
  end
  return table.concat(o)
end

local function from_hex(s)
  if #s % 2 ~= 0 then return nil end
  local o = {}
  for i = 1, #s, 2 do
    local hi = string.find(HEXD, string.sub(s, i, i), 1, true)
    local lo = string.find(HEXD, string.sub(s, i + 1, i + 1), 1, true)
    if not hi or not lo then return nil end
    o[#o + 1] = string.char((hi - 1) * 16 + (lo - 1))
  end
  return table.concat(o)
end

local function u16(v)
  v = math.floor(v) % 65536
  return string.char(v % 256, math.floor(v / 256))
end

local function b(s, i) return string.byte(s, i) or 0 end
local function r16(s, i) return b(s, i) + b(s, i + 1) * 256 end

local function pack(kind, f)
  if kind == M.KIND.BEACON then
    local nm = string.sub(tostring(f.name or "?"), 1, 8)
    return u16(f.id or 0) .. nm
  elseif kind == M.KIND.CHALLENGE or kind == M.KIND.ACCEPT then
    -- The starter id MUST travel with the collection. capture_targets()
    -- filters it out on the winner's side, and with no starter byte that
    -- filter silently compares against zero and shields nothing.
    return u16(f.sid) .. string.char(f.trio[1], f.trio[2], f.trio[3])
           .. f.bm .. string.char(f.starter)
  elseif kind == M.KIND.COMMIT then
    return u16(f.sid) .. u16(f.commitment)
  elseif kind == M.KIND.REVEAL then
    return u16(f.sid) .. string.char(f.pick) .. u16(f.nonce)
  elseif kind == M.KIND.RESULT then
    return u16(f.sid) .. string.char(f.winner, f.hostpick, f.joinpick, f.coin)
  elseif kind == M.KIND.TARGET then
    return u16(f.sid) .. string.char(f.species)
  elseif kind == M.KIND.OUTCOME then
    return u16(f.sid) .. string.char(f.caught, f.species)
  end
  return nil
end

local function species_ok(v) return v >= 1 and v <= dex.COUNT end

local function unpack_body(kind, s)
  if kind == M.KIND.BEACON then
    if #s < 3 or #s > 10 then return nil end
    return {id = r16(s, 1), name = string.sub(s, 3)}
  elseif kind == M.KIND.CHALLENGE or kind == M.KIND.ACCEPT then
    if #s ~= 11 then return nil end
    local trio = {b(s, 3), b(s, 4), b(s, 5)}
    for i = 1, 3 do if not species_ok(trio[i]) then return nil end end
    local starter = b(s, 11)
    if not species_ok(starter) then return nil end
    return {sid = r16(s, 1), trio = trio, bm = string.sub(s, 6, 10),
            starter = starter}
  elseif kind == M.KIND.COMMIT then
    if #s ~= 4 then return nil end
    return {sid = r16(s, 1), commitment = r16(s, 3)}
  elseif kind == M.KIND.REVEAL then
    if #s ~= 5 then return nil end
    local pick = b(s, 3)
    if pick < 1 or pick > 3 then return nil end
    return {sid = r16(s, 1), pick = pick, nonce = r16(s, 4)}
  elseif kind == M.KIND.RESULT then
    if #s ~= 6 then return nil end
    local winner, hp, jp, coin = b(s, 3), b(s, 4), b(s, 5), b(s, 6)
    if winner > 2 then return nil end
    if hp < 1 or hp > 3 or jp < 1 or jp > 3 then return nil end
    if coin > 1 then return nil end
    return {sid = r16(s, 1), winner = winner, hostpick = hp, joinpick = jp, coin = coin}
  elseif kind == M.KIND.TARGET then
    if #s ~= 3 then return nil end
    local sp = b(s, 3)
    if not species_ok(sp) then return nil end
    return {sid = r16(s, 1), species = sp}
  elseif kind == M.KIND.OUTCOME then
    if #s ~= 4 then return nil end
    local caught, sp = b(s, 3), b(s, 4)
    if caught > 1 or not species_ok(sp) then return nil end
    return {sid = r16(s, 1), caught = caught, species = sp}
  end
  return nil
end

function M.encode(kind, fields)
  local body = pack(kind, fields)
  if not body then return nil end
  if hex_mode then body = to_hex(body) end
  return M.PREFIX .. kind .. body
end

function M.decode(payload)
  if type(payload) ~= "string" then return nil end
  if #payload < 4 or #payload > 44 then return nil end
  if string.sub(payload, 1, 3) ~= M.PREFIX then return nil end
  local kind = string.sub(payload, 4, 4)
  if not KNOWN[kind] then return nil end
  local body = string.sub(payload, 5)
  if hex_mode then
    body = from_hex(body)
    if body == nil then return nil end
  end
  local fields = unpack_body(kind, body)
  if not fields then return nil end
  return kind, fields
end

function M.enable()
  enabled = badge.radio.enable() and true or false
  if enabled then
    badge.radio.on_recv(function(mac, rssi, payload)
      local kind, fields = M.decode(payload)
      if kind and handler then handler(mac, rssi, kind, fields) end
    end)
  end
  return enabled
end

function M.disable()
  if not enabled then return end
  -- Never unregister inside the handler: several frames may already be
  -- scheduled for this tick. Disabling on exit is the documented way.
  badge.radio.on_recv(nil)
  badge.radio.disable()
  enabled = false
end

function M.is_on() return enabled end
function M.on_frame(fn) handler = fn end

function M.send(kind, fields)
  if not enabled then return false end
  local p = M.encode(kind, fields)
  if not p or #p > 44 then return false end
  return badge.radio.send(p)
end

return M
```

`KNOWN` is a kind whitelist only. Every real length check lives in
`unpack_body`, next to the fields it guards, so a frame's size and its
contents can never drift apart.

```lua
function duel_trio()
  if trio and duelmod.legal(trio) then return trio end
  local best = {}
  for id = 1, dex.COUNT do
    if own.has(id) then
      local t = dex.type(id)
      if not best[t] or dex.strength(id) > dex.strength(best[t]) then
        best[t] = id
      end
    end
  end
  local out = {}
  for t = 1, 6 do
    if best[t] and #out < 3 then out[#out + 1] = best[t] end
  end
  if #out < 3 then return nil end
  trio = out
  return trio
end

function set_trio_slot(species)
  if not own.has(species) then return end
  local t = dex.type(species)
  local cur_trio = duel_trio()
  if not cur_trio then return end
  for i = 1, 3 do
    if dex.type(cur_trio[i]) == t then cur_trio[i] = species; return end
  end
end

function trio_missing()
  local n = #own.types_held()
  if n >= 3 then return 0 end
  return 3 - n

-- A peer name is untrusted text from a stranger's badge. Strip it to
-- printable ASCII and cap it before it ever reaches a label: the bundled
-- fonts have no glyphs for anything else, and a control byte in a label is
-- a rendering bug waiting to happen.
local function clean_name(s)
  local o = {}
  for i = 1, #s do
    local c = string.byte(s, i)
    if c >= 32 and c < 127 and #o < 8 then o[#o + 1] = string.char(c) end
  end
  if #o == 0 then return "?" end
  return table.concat(o)
end

function peers()
  local now = badge.sys.ms()
  local out = {}
  for i = 1, #peer_list do
    if now - peer_list[i].seen_ms <= PEER_TTL_MS then out[#out + 1] = peer_list[i] end
  end
  table.sort(out, function(a, b) return a.rssi > b.rssi end)
  return out
end

function note_peer(mac, rssi, fields)
  local now = badge.sys.ms()
  for i = 1, #peer_list do
    if peer_list[i].mac == mac then
      peer_list[i].rssi = rssi
      peer_list[i].name = clean_name(fields.name or "?")
      peer_list[i].seen_ms = now
      return
    end
  end
  if #peer_list >= 12 then table.remove(peer_list, 1) end
  peer_list[#peer_list + 1] = {mac = mac, id = fields.id,
    name = clean_name(fields.name or "?"), rssi = rssi, seen_ms = now}
end

function beacon_pump(now)
  if not net.is_on() then return end
  if now - last_beacon < BEACON_MS then return end
  last_beacon = now
  net.send(net.KIND.BEACON, {id = 0, name = badge.me.name() or "?"})
end
```

```lua
function duel_frame(mac, rssi, kind, fields)
  -- Every frame after the beacon is filtered on the session id, so two
  -- duels running in the same room never corrupt each other.
  if D.state == "idle" then
    if kind == net.KIND.CHALLENGE and trio_missing() == 0 and duel_trio() then
      duel_reset()
      D.role, D.state, D.sid, D.peer_mac = "join", "commit", fields.sid, mac
      D.peer_trio, D.peer_bm = fields.trio, fields.bm
      D.last_rx = badge.sys.ms()
      badge.sys.wake_lock(true)
      D.peer_starter = fields.starter
      net.send(net.KIND.ACCEPT, {sid = D.sid, trio = duel_trio(),
        bm = own.bitmap(), starter = own.starter()})
      show("DUEL")
    end
    return
  end
  if fields.sid ~= D.sid then return end
  D.last_rx = badge.sys.ms()

  if kind == net.KIND.ACCEPT and D.state == "offer" then
    D.peer_trio, D.peer_bm = fields.trio, fields.bm
    D.peer_starter = fields.starter
    D.state = "commit"
  elseif kind == net.KIND.COMMIT then
    D.peer_commit = fields.commitment
  elseif kind == net.KIND.REVEAL then
    -- THE CHEAT GUARD. A reveal is only accepted once WE have committed and
    -- we hold the peer's commitment to check it against. Without both, a
    -- badge could simply wait and read the pick before choosing.
    if D.my_commit == nil or D.peer_commit == nil then return end
    if not duelmod.verify(D.peer_commit, fields.pick, fields.nonce) then
      D.peer_pick = nil
      D.winner = "me"
      D.state = "target"
      return
    end
    D.peer_pick = fields.pick
  elseif kind == net.KIND.RESULT and D.role == "join" then
    D.winner = (fields.winner == 2) and "me" or "them"
    D.state = (D.winner == "me") and "target" or "over"
  elseif kind == net.KIND.TARGET and D.role == "host" and D.winner == "them" then
    D.target = fields.species
  elseif kind == net.KIND.OUTCOME then
    if fields.caught == 1 then
      if D.winner == "me" then own.record_catch(fields.species)
      else own.remove(fields.species) end
      own.save()
    end
    D.state = "over"
  end
```

```lua
function duel_tick(now)
  if D.state == "idle" then return end

  -- A peer who walks out of range must not hang the duel forever. Nothing
  -- transfers on a timeout.
  if now - D.last_rx > DUEL_TIMEOUT_MS and D.state ~= "over" then
    D.state = "over"
    D.winner = D.winner or "them"
    screens.DUEL.head:set_text("CONNECTION LOST")
    screens.DUEL.foot:set_text("A back to the map")
    return
  end

  -- Retransmit at a fixed cadence. Every frame is idempotent and
  -- latest-wins, so there are no acknowledgements to track.
  if now - D.last_tx >= 400 then
    D.last_tx = now
    if D.state == "offer" then
      net.send(net.KIND.CHALLENGE, {sid = D.sid, trio = duel_trio(),
        bm = own.bitmap(), starter = own.starter()})
    elseif D.state == "commit" and D.my_commit then
      net.send(net.KIND.COMMIT, {sid = D.sid, commitment = D.my_commit})
      -- Reveal only once the peer has committed, never before.
      if D.peer_commit then
        net.send(net.KIND.REVEAL,
          {sid = D.sid, pick = D.my_pick, nonce = D.my_nonce})
      end
    end
  end

  if D.state == "commit" and D.my_pick and D.peer_pick and D.role == "host" then
    resolve_and_broadcast()
  end

  if D.state == "capture" then
    if resumed() then
      D.win = catch.new_window()
      return
    end
    local phase = catch.window_step(D.win, now, badge.sensor.shake())
    if phase == "shaking" then
      led_scene("shaking")
      screens.DUEL.meter:set_value(math.floor(
        math.min(D.win.shakes, catch.SHAKE_TARGET) * 100 / catch.SHAKE_TARGET))
      screens.DUEL.foot:set_text("SHAKE!")
    elseif phase == "countdown" then
      screens.DUEL.foot:set_text("get ready")
    else
      screens.DUEL.foot:set_text("THROW IT")
      local x, y, z = badge.sensor.accel()
      if x and catch.feed(D.th, x, y, z) then
        local pct = catch.chance(dex.strength(D.target),
          catch.shake_mult(D.win), catch.THROW_MULT[D.th.grade],
          own.caught(D.target))
        local got = badge.sys.random(100) < pct
        if got then own.record_catch(D.target); own.save() end
        net.send(net.KIND.OUTCOME,
          {sid = D.sid, caught = got and 1 or 0, species = D.target})
        D.state = "over"
        led_scene(got and "duel_win" or "duel_loss")
        screens.DUEL.head:set_text(got and ("YOU TOOK " .. dex.name(D.target))
                                        or "IT BROKE FREE")
      end
    end
  end
end
```

```lua
    pump = function()
      for _, pair in ipairs({{a, b}, {b, a}}) do
        local from, to = pair[1], pair[2]
        while #from.M.sent > 0 do
          local p = table.remove(from.M.sent, 1)
          if math.random(100) > drop_pct then
            pending[#pending + 1] = {to = to, payload = p}
          end
        end
      end
      -- Reorder: deliver in a shuffled order, and hold some back a tick.
      for i = #pending, 2, -1 do
        local j = math.random(i)
        pending[i], pending[j] = pending[j], pending[i]
```

```lua
-- A white flash, then the new creature's type colour chasing clockwise.
function LED.hatch(t)
  local phase = t % 2400
  if phase < 200 then
    badge.led.set_all(255, 255, 255)
    return
  end
  local c = dex.TYPE_COLOR[hatched_type][1]
  local i = math.floor(phase / 120) % 6 + 1
  badge.led.set(i, math.floor(c / 65536) % 256,
                math.floor(c / 256) % 256, c % 256)
end

-- Held between the shake window closing and the throw landing, so the
-- player can feel that the badge is waiting for the gesture.
function LED.armed(t)
  badge.led.set_all(60, 60, 60)
end

-- One, two or three green flashes for Nice, Great and Excellent. The count
-- is the message, so it must be countable at a glance.
function LED.grade(t)
  if (t % 400) >= 220 then return end
  for i = 1, grade_n do badge.led.set(i, 40, 230, 90) end
end

-- Both picks at once: mine on the left column, theirs on the right.
function LED.reveal(t)
  local mine = D.my_pick and duel_trio() and duel_trio()[D.my_pick]
  local theirs = D.peer_pick and D.peer_trio and D.peer_trio[D.peer_pick]
  local function paint(id, slots)
    if not id then return end
    local c = dex.TYPE_COLOR[dex.type(id) or 1][1]
    for _, i in ipairs(slots) do
      badge.led.set(i, math.floor(c / 65536) % 256,
                    math.floor(c / 256) % 256, c % 256)
    end
  end
  paint(mine, {1, 6, 5})
  paint(theirs, {2, 3, 4})
end

-- A slow red fade, one pulse a second for three seconds. Losing a creature
-- is the worst thing that happens in this game and it should feel like it.
function LED.lost_one(t)
  local since = t - lost_at
  if since > 3000 then return end
  local k = breathe(t, 1000)
  badge.led.set_all(math.floor(k * 0.7), 0, 0)
end

function set_grade_flash(n)
  grade_n = math.max(0, math.min(3, math.floor(n)))
end

function note_hatch(id)
  hatched_type = dex.type(id) or 1
  led_scene("hatch")
end

function note_loss(now)
  lost_at = now
  led_scene("lost_one")
end
```

```sh
#!/bin/sh
# Share caps the whole app directory at 48 KiB across 16 files. Exceeding it
# means other badges cannot receive the app at all, which is silent until
# someone tries.
set -e
LIMIT=49152
FILE_LIMIT=16
total=0
count=0
echo "file                       bytes"
for f in app/*; do
  n=$(wc -c < "$f")
  total=$((total + n))
  count=$((count + 1))
  printf "%-26s %6d\n" "$(basename "$f")" "$n"
done
# icon.bin is 5,304 bytes if the IDE image path is used. Budget for it even
# when it is not in the repo.
echo "---"
printf "%-26s %6d\n" "files" "$count"
printf "%-26s %6d\n" "total" "$total"
printf "%-26s %6d\n" "total + icon.bin" "$((total + 5304))"
printf "%-26s %6d\n" "limit" "$LIMIT"
[ "$count" -le "$FILE_LIMIT" ] || { echo "FAIL: too many files"; exit 1; }
[ "$((total + 5304))" -le "$LIMIT" ] || { echo "FAIL: bundle over 48 KiB"; exit 1; }
echo "bundle OK"
```
